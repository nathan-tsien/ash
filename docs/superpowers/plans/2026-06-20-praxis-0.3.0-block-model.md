# praxis 0.3.0 Block-Model Migration — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate ash from the flat praxis 0.2.0 event/history model to the breaking 0.3.0 block-oriented (Anthropic message-turn) model, adopting `ContentBlock[]` natively in the ash view-model.

**Architecture:** Contract-first (ADR-0016): regenerate types from the vendored 0.3.0 OpenAPI, re-point the `runtime-events.ts` aliases, then rewrite the two projection cores — the SSE reducer (`runtime-event-reducer.ts`, folds `StreamEvent` turn lifecycle) and the history projection (`history-projection.ts`, folds `Message[]`) — into a block-shaped shared `Message`. UI (chat bubble, tool trace) renders blocks. SSE stays the one hand-written transport but consumes the generated `StreamEvent` union.

**Tech Stack:** TypeScript (strict), `openapi-typescript` + `openapi-fetch`, Next.js App Router, Vitest, pnpm/turbo.

## Global Constraints

- Base branch: this plan is built on `main` AFTER PR #37 (workbench UX polish) merges. Branch: `feat/praxis-0.3.0-block-model`.
- ALL praxis types come from `generated.ts` (`openapi-typescript`); runtime calls via `openapi-fetch`. No hand-written request/response shapes. SSE (`sse.ts`/`streamEvents`) is the only hand-written transport and still imports the generated `StreamEvent`. (ADR-0016)
- Vendored contract pinned tag: `openapi-v0.3.0`. `sync:praxis:check` and `gen:praxis:check` must pass (no drift).
- No raw palette literals / arbitrary `text-[..]`; semantic tokens only (design-guidelines / ADR-0013). zh-CN user strings via i18n; English comments/logs.
- TDD: every fold/mapping change is driven by a failing test first. `pnpm typecheck && pnpm lint && pnpm build && pnpm test` green before each commit.
- No cogito import graph into `apps/web` / `packages/ui`.

## Generated types (source of truth — copied from `generated.ts` @ 0.3.0)

```ts
// StreamEvent (internally tagged by `type`)
type StreamEvent =
  | { type: "message_start"; message: Message }
  | { type: "content_block_start"; index: number; content_block: ContentBlock }
  | { type: "content_block_delta"; index: number; delta: BlockDelta }
  | { type: "content_block_stop"; index: number }
  | { type: "message_delta"; stop_reason?: StopReason; usage?: Usage }
  | { type: "message_stop" }
  | { type: "turn_paused" } | { type: "turn_resumed" }
  | { type: "skill_activation_requested"; /* skill fields */ }
  | { type: "stream_end"; task_status: TaskStatus }
  | { type: "ping" };

// ContentBlock (adjacent tagged: {type, data})
type ContentBlock =
  | { type: "text"; data: { text: string; citations?: Citation[] } }
  | { type: "thinking"; data: { text: string; redacted?: boolean } }
  | { type: "tool_use"; data: { call_id: string; tool_name: string; args: Record<string, unknown>; source?: Source; display?: Display } }
  | { type: "tool_result"; data: { call_id: string; /* output/error fields */ } }
  | { type: "image"; data: { /* image source fields */ } };

// BlockDelta (internally tagged)
type BlockDelta =
  | { type: "text_delta"; text: string }
  | { type: "thinking_delta"; thinking: string }
  | { type: "input_json_delta"; partial_json: string }
  | { type: "signature_delta"; signature: string }
  | { type: "citations_delta"; citation: Citation };

type Message = { id: string; task_id: string; seq: number; role: MessageRole;
  content?: ContentBlock[]; stop_reason?: StopReason; usage?: Usage; model?: string;
  attachments?: Attachment[]; error?: MessageError; created_at: string };
type MessagePage = { items: Message[]; next_before_seq?: number };
type StopReason = "end_turn" | "max_tokens" | "stop_sequence" | "awaiting_input" | "cancelled" | "failed";
type Usage = { input_tokens: number; output_tokens: number };
```

### Task 5: Rewrite the SSE reducer to fold `StreamEvent`

**Files:**
- Modify: `apps/web/src/lib/praxis/runtime-event-reducer.ts`
- Test: `apps/web/src/lib/praxis/__tests__/runtime-event-reducer.test.ts` (rewrite)

**Interfaces — Consumes:** `block-fold` helpers, `StreamEvent`, view-model `Message`/`Task`. **Produces:** `runtimeEventReducer(state, event: StreamEvent): ReducerState` where state tracks the in-flight praxis message (`content_block`s by index + per-block `jsonAcc`) and projects the finalized blocks into the view-model `Message`.

Fold rules (each its own RED→GREEN cycle — write the test, watch fail, implement, watch pass):
- [ ] **5a `message_start`** opens an assistant view `Message` (`isStreaming: true`, empty `blocks`, id = `message.id`).
- [ ] **5b `content_block_start`** stores the praxis block at `index`; appends `praxisBlockToAsh(block)` to the view Message.
- [ ] **5c `content_block_delta` text_delta** appends to the indexed text block and the view block.
- [ ] **5d `content_block_delta` thinking_delta** appends to the indexed thinking block.
- [ ] **5e `content_block_delta` input_json_delta** accumulates `jsonAcc[index]` (view tool_use `args` stays `{}` until stop).
- [ ] **5f `content_block_stop`** for a tool_use block: `args = finalizeToolArgs(jsonAcc[index])`; updates the view block.
- [ ] **5g `message_delta`** sets `stopReason` + stashes `usage`.
- [ ] **5h `message_stop`** clears `isStreaming`.
- [ ] **5i control events**: `turn_paused` -> task `status = "awaiting_input"`; `turn_resumed` -> `"running"`; `stream_end` -> map `task_status` to terminal view status; `ping` -> no-op; `skill_activation_requested` -> log (no view change in this slice).
- [ ] **5j Commit** `feat(praxis): fold StreamEvent turn lifecycle in the reducer`.

Representative test (5e+5f, the tricky one):

```ts
it("assembles tool_use args from input_json_delta across content_block_stop", () => {
  let s = init();
  s = runtimeEventReducer(s, { type: "message_start", message: msg("m1", "assistant") });
  s = runtimeEventReducer(s, { type: "content_block_start", index: 0, content_block: { type: "tool_use", data: { call_id: "c1", tool_name: "slides.render", args: {} } } });

  s = runtimeEventReducer(s, { type: "content_block_stop", index: 0 });
  const block = s.task.messages.at(-1)!.blocks[0];
  expect(block).toMatchObject({ kind: "tool_use", callId: "c1", args: { theme: "x" } });
```
